\# AI Chatbot



A simple AI-powered chatbot built using Python, Flask, Google Gemini AI, HTML, CSS, and JavaScript.



\## Features



\- AI-powered chat responses

\- Simple and clean web interface

\- Real-time interaction

\- Quick suggestion buttons

\- Responsive design

\- Gemini AI integration

\- Secure API key handling using environment variables



\## Technologies Used



\- Python

\- Flask

\- Google Gemini AI

\- HTML5

\- CSS3

\- JavaScript

\- dotenv
